# RailTrack India v3

Upload `index.html` at repository root and upload the five JavaScript files inside an `api/` folder.

Required Vercel Environment Variable:
RAILRADAR_API_KEY = your RailRadar API key

This version:
- only accepts station suggestions that contain a valid station code
- searches stations by name or code
- searches NTES train number/name
- finds trains between selected stations
- opens live train location + route
- keeps the RailRadar API key server-side
